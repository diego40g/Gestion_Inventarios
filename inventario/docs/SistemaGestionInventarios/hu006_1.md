# 🔴 HU-006: Implementar Modelo de Ventas con Composición

**Sprint:** 2 | **Estimación:** 8 SP | **Prioridad:** Crítica

---

## 📝 Descripción

**Como** administrador del sistema,  
**Quiero** registrar ventas con múltiples productos,  
**Para** llevar control de las transacciones y reducir automáticamente el stock.

---

## ✅ Criterios de Aceptación

### Clase ItemVenta

- [ ] Atributos privados: `private int productoId`, `private String nombreProducto`, `private int cantidad`, `private double precioUnitario`
- [ ] Constructor con validaciones
- [ ] Getters y setters apropiados
- [ ] Método `public double calcularSubtotal()` retorna `cantidad * precioUnitario`
- [ ] Validar cantidad > 0
- [ ] Validar precioUnitario > 0

### Clase Venta

- [ ] Atributos privados:
  - `private int id` (generado automáticamente con contador estático)
  - `private List<ItemVenta> items` (inicializar con `new ArrayList<>()`)
  - `private LocalDateTime fecha` (inicializar con `LocalDateTime.now()`)
  - `private boolean completada`
  - `private double descuentoAplicado`
  - `private Integer clienteId` (puede ser null)

### Métodos de Venta

- [ ] `public void agregarItem(ItemVenta item)` - Lanza excepción si ya completada
- [ ] `public boolean eliminarItem(int productoId)` - Retorna true si eliminó
- [ ] `public double calcularSubtotal()` - Suma subtotales de items
- [ ] `public double calcularDescuento()` - Calcula monto descuento
- [ ] `public double calcularTotal()` - Subtotal - descuento
- [ ] `public boolean completarVenta()` - Marca como completada si tiene items

### Validaciones

- [ ] No agregar items con cantidad <= 0
- [ ] No completar venta sin items
- [ ] No modificar venta completada (lanzar `IllegalStateException`)
- [ ] Validar que items no sea null

### Constructores

- [ ] Constructor que genera ID automáticamente
- [ ] Constructor con clienteId opcional

---

## 🧪 Casos de Prueba

### Caso Normal

```java
Venta venta = new Venta();
ItemVenta item1 = new ItemVenta(1, "Laptop", 2, 999.99);
ItemVenta item2 = new ItemVenta(2, "Mouse", 3, 25.50);

venta.agregarItem(item1);
venta.agregarItem(item2);

assertEquals(2076.48, venta.calcularSubtotal(), 0.01);
assertTrue(venta.completarVenta());
assertTrue(venta.isCompletada());
```

### Casos Borde

- [ ] Agregar item con cantidad negativa (debe lanzar `IllegalArgumentException`)
- [ ] Completar venta sin items (debe lanzar `IllegalStateException`)
- [ ] Modificar venta completada (debe lanzar `IllegalStateException`)
