# 🔴 HU-006: Implementar Modelo de Ventas con Composición

**Sprint:** 2 | **Estimación:** 8 SP | **Prioridad:** Crítica

---

## 📝 Descripción

**Como** administrador del sistema,  
**Quiero** registrar ventas con múltiples productos,  
**Para** llevar control de las transacciones y reducir automáticamente el stock.

---

## ✅ Criterios de Aceptación

### Clase ItemVenta (Dataclass)

- [ ] Atributos: `producto_id: int`, `nombre_producto: str`, `cantidad: int`, `precio_unitario: float`
- [ ] Método `calcular_subtotal()` retorna `cantidad * precio_unitario`
- [ ] Validar cantidad > 0
- [ ] Validar precio_unitario > 0

### Clase Venta (Dataclass)

- [ ] Atributos:
  - `id: int` (generado automáticamente)
  - `items: List[ItemVenta] = field(default_factory=list)`
  - `fecha: datetime = field(default_factory=datetime.now)`
  - `completada: bool = False`
  - `descuento_aplicado: float = 0.0`
  - `cliente_id: Optional[int] = None`

### Métodos de Venta

- [ ] `agregar_item(item: ItemVenta)` - No permite si completada
- [ ] `eliminar_item(producto_id: int) -> bool`
- [ ] `calcular_subtotal()` - Suma subtotales de items
- [ ] `calcular_descuento()` - Calcula monto descuento
- [ ] `calcular_total()` - Subtotal - descuento
- [ ] `completar_venta(repositorio_productos) -> bool` - Reduce stock y marca completada

### Validaciones

- [ ] No agregar items con cantidad <= 0
- [ ] No completar venta sin items
- [ ] No modificar venta completada
- [ ] Verificar stock antes de completar
