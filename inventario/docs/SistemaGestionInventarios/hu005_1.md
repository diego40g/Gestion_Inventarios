# 🔴 HU-005: Implementar Jerarquía de Productos con Clase Abstracta

**Sprint:** 2 | **Estimación:** 8 SP | **Prioridad:** Crítica

---

## 📝 Descripción

**Como** desarrollador del sistema,  
**Quiero** crear una jerarquía de productos usando herencia y clases abstractas,  
**Para** modelar diferentes tipos de productos con comportamientos específicos.

---

## ✅ Criterios de Aceptación

### Clase Abstracta Producto

- [ ] Declarar como `public abstract class Producto`
- [ ] Constructor con parámetros: nombre, descripcion, precio, stock, categoriaId, proveedorId
- [ ] Constructor sobrecargado simplificado: nombre, precio, stock
- [ ] ID generado automáticamente con `generarId()` (método estático privado sincronizado)
- [ ] Atributos privados con getters/setters protegidos
- [ ] Método abstracto `public abstract String getTipoProducto()`
- [ ] Método abstracto `public abstract double calcularPrecioFinal()`
- [ ] Implementar `toString()`: `"[{tipoProducto}] {nombre} (${precio}) - Stock: {stock}"`

### ProductoFisico extends Producto

- [ ] Heredar de Producto usando `extends`
- [ ] Atributos privados: `private double pesoKg`, `private String dimensiones`
- [ ] Constructor: `(String nombre, double precio, int stock, double pesoKg, String dimensiones)`
- [ ] Llamar a `super(nombre, precio, stock)` en constructor
- [ ] Implementar `getTipoProducto()` retorna `"FISICO"`
- [ ] `calcularPrecioFinal()` incluye costo envío: `getPrecio() + (pesoKg * 2.5)`
- [ ] Método `public double calcularCostoEnvio(String destino)` con Map de tarifas

### ProductoDigital extends Producto

- [ ] Heredar de Producto
- [ ] Stock "infinito" usando `super(nombre, precio, 999999)` en constructor
- [ ] Atributos: `private double tamañoMb`, `private String formato`, `private String urlDescarga`
- [ ] Constructor: `(String nombre, double precio, double tamañoMb, String formato, String urlDescarga)`
- [ ] Implementar `getTipoProducto()` retorna `"DIGITAL"`
- [ ] `calcularPrecioFinal()` retorna precio base sin modificaciones
- [ ] Método `public String generarEnlaceDescarga()` con token temporal usando `LocalDateTime.now().hashCode()`

### ProductoPerecible extends Producto

- [ ] Heredar de Producto
- [ ] Atributos: `private LocalDate fechaVencimiento`, `private double temperaturaConservacion`
- [ ] Constructor: `(String nombre, double precio, int stock, LocalDate fechaVencimiento, double temp)`
- [ ] Llamar a `super(nombre, precio, stock)` en constructor
- [ ] Implementar `getTipoProducto()` retorna `"PERECIBLE"`
- [ ] `calcularPrecioFinal()` aplica descuento progresivo:
  - Vencido (<=0 días): precio = 0
  - 1-3 días: 50% descuento (precio \* 0.5)
  - 4-7 días: 25% descuento (precio \* 0.75)
  - Más de 7 días: sin descuento (precio completo)
- [ ] Método `public boolean estaVencido()` retorna boolean
- [ ] Método `public long diasParaVencer()` retorna días hasta vencimiento usando `ChronoUnit.DAYS`

### Uso de super()

- [ ] Todas las subclases llaman a `super()` en el constructor

## 🧪 Casos de Prueba

### Caso Normal

```java
// IDs se generan automáticamente
ProductoFisico laptop = new ProductoFisico("Laptop HP", 999.99, 10, 2.5, "40x30x3 cm");
assertEquals("FISICO", laptop.getTipoProducto());
double precioConEnvio = 999.99 + (2.5 * 2.5); // precio + (peso * 2.5)
assertEquals(precioConEnvio, laptop.calcularPrecioFinal(), 0.01);

ProductoDigital ebook = new ProductoDigital("Curso Python Pro", 49.99, 500, "mp4", "https://cursos.com/python");
assertEquals("DIGITAL", ebook.getTipoProducto());
assertEquals(49.99, ebook.calcularPrecioFinal(), 0.01); // Sin costo adicional
assertNotNull(ebook.generarEnlaceDescarga());

ProductoPerecible leche = new ProductoPerecible("Leche Orgánica", 2.50, 100,
    LocalDate.now().plusDays(5), 4.0); // 5 días para vencer
assertEquals("PERECIBLE", leche.getTipoProducto());
// 5 días = descuento 25% (dentro del rango 4-7 días)
assertEquals(2.50 * 0.75, leche.calcularPrecioFinal(), 0.01);
assertFalse(leche.estaVencido());
```
