# 🟠 HU-007: Definir Interfaces con ABC para Repositorios

**Sprint:** 3 | **Estimación:** 5 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** desarrollador del sistema,  
**Quiero** definir interfaces usando ABC para los repositorios,  
**Para** establecer contratos que las implementaciones concretas deben cumplir.

---

## ✅ Criterios de Aceptación

### Interface Repositorio[T] (Genérica)

- [ ] Heredar de `ABC` y usar `Generic[T]`
- [ ] Variable de tipo `T = TypeVar('T')`
- [ ] Métodos abstractos:
  - `guardar(entidad: T) -> T`
  - `obtener_por_id(id: int) -> Optional[T]`
  - `obtener_todos() -> List[T]`
  - `actualizar(entidad: T) -> bool`
  - `eliminar(id: int) -> bool`
  - `existe(id: int) -> bool`

### Interface Observador

- [ ] Método abstracto `actualizar(mensaje: str, datos: dict) -> None`

### Interface Sujeto

- [ ] Atributo `_observadores: List[Observador]`
- [ ] Métodos concretos (no abstractos):
  - `agregar_observador(observador: Observador)`
  - `eliminar_observador(observador: Observador)`
  - `notificar_observadores(mensaje: str, datos: dict)`

### Documentación

- [ ] Cada interface con docstring explicativo
- [ ] Documentar parámetros y retornos
- [ ] Incluir ejemplos de uso
