# 🟠 HU-007: Definir Interfaces para Repositorios

**Sprint:** 3 | **Estimación:** 5 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** desarrollador del sistema,  
**Quiero** definir interfaces usando Java interfaces para los repositorios,  
**Para** establecer contratos que las implementaciones concretas deben cumplir.

---

## ✅ Criterios de Aceptación

### Interface Repositorio<T> (Genérica)

- [ ] Declarar como `public interface Repositorio<T>`
- [ ] Usar genéricos de Java para el tipo T
- [ ] Métodos abstractos:
  - `void agregar(T entidad)` - Agrega entidad al repositorio
  - `Optional<T> obtener(int id)` - Obtiene entidad por ID
  - `List<T> obtenerTodos()` - Obtiene todas las entidades
  - `boolean actualizar(T entidad)` - Actualiza entidad existente
  - `boolean eliminar(int id)` - Elimina entidad por ID
  - `List<T> buscar(String criterio)` - Busca por criterio

### Interface Observador

- [ ] Método abstracto `void actualizar(String mensaje, Map<String, Object> datos)`

### Clase Abstracta Sujeto

- [ ] Declarar como `public abstract class Sujeto` (NO es interface)
- [ ] Atributo privado `private final List<Observador> observadores`
- [ ] Métodos concretos (implementados):
  - `public void agregarObservador(Observador observador)`
  - `public void eliminarObservador(Observador observador)`
  - `protected void notificar(String mensaje, Map<String, Object> datos)`
  - `protected List<Observador> getObservadores()` - Retorna lista inmutable

### Documentación

- [ ] Cada interface con JavaDoc explicativo
- [ ] Documentar parámetros y retornos con `@param` y `@return`
- [ ] Incluir ejemplos de uso con `@see` o `@example`
