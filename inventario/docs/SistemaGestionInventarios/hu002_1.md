# 🔴 HU-002: Implementar Clase Proveedor con Atributos Completos

**Sprint:** 1 | **Estimación:** 3 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** administrador del sistema,  
**Quiero** tener una clase `Proveedor` que almacene información de contacto,  
**Para** gestionar los proveedores de productos del inventario.

---

## ✅ Criterios de Aceptación

### Atributos Privados

- [ ] `private int id` - Identificador único del proveedor
- [ ] `private String nombre` - Nombre o razón social
- [ ] `private String contacto` - Nombre de la persona de contacto
- [ ] `private String telefono` - Teléfono de contacto
- [ ] `private String email` - Correo electrónico
- [ ] `private String direccion` - Dirección física (default "")
- [ ] `private boolean activo` - Estado del proveedor (default true)

### Constructores

- [ ] Constructor completo con todos los parámetros
- [ ] Constructor sobrecargado con valores por defecto para `direccion` y `activo`
- [ ] Validaciones en constructores

### Métodos Getters y Setters

- [ ] Getters para todos los atributos
- [ ] Setters con validaciones para `nombre`, `email`, `telefono`

### Métodos de Instancia

- [ ] `toString()` debe retornar: `"{nombre} - {telefono}"`
- [ ] `validarEmail()` debe verificar formato de email básico (contiene @)
- [ ] `validarTelefono()` debe verificar que tenga al menos 7 caracteres

### Validaciones

- [ ] El email debe contener el símbolo `@`
- [ ] El teléfono debe tener al menos 7 caracteres
- [ ] El nombre no puede estar vacío o null

---

## 🧪 Casos de Prueba

### Caso Normal

```java
Proveedor proveedor = new Proveedor(
    1,
    "Tech Distributors SA",
    "Juan Pérez",
    "+1234567890",
    "juan@techdist.com",
    "Calle Principal 123",
    true
);
assertEquals("Tech Distributors SA - +1234567890", proveedor.toString());
assertTrue(proveedor.validarEmail());
```

### Casos Borde

- [ ] Email sin símbolo @ (debe lanzar `IllegalArgumentException`)
- [ ] Teléfono con menos de 7 caracteres (debe lanzar `IllegalArgumentException`)
- [ ] Proveedor con nombre vacío (debe lanzar `IllegalArgumentException`)
- [ ] Creación sin dirección (debe usar cadena vacía por defecto)
