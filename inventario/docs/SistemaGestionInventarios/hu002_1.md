# 🔴 HU-002: Implementar Clase Proveedor con Atributos Completos

**Sprint:** 1 | **Estimación:** 3 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** administrador del sistema,  
**Quiero** tener una clase `Proveedor` que almacene información de contacto,  
**Para** gestionar los proveedores de productos del inventario.

---

## ✅ Criterios de Aceptación

### Atributos Obligatorios

- [ ] `id: int` - Identificador único del proveedor
- [ ] `nombre: str` - Nombre o razón social
- [ ] `contacto: str` - Nombre de la persona de contacto
- [ ] `telefono: str` - Teléfono de contacto
- [ ] `email: str` - Correo electrónico

### Atributos Opcionales

- [ ] `direccion: str = ""` - Dirección física
- [ ] `activo: bool = True` - Estado del proveedor

### Métodos de Instancia

- [ ] `__str__()` debe retornar: `"{nombre} - {telefono}"`
- [ ] `validar_email()` debe verificar formato de email básico (contiene @)
- [ ] `validar_telefono()` debe verificar que solo contenga números y caracteres válidos

### Validaciones

- [ ] El email debe contener el símbolo `@`
- [ ] El teléfono debe tener al menos 7 caracteres
- [ ] El nombre no puede estar vacío

---

## 🧪 Casos de Prueba

### Caso Normal

```python
proveedor = Proveedor(
    id=1,
    nombre="Tech Distributors SA",
    contacto="Juan Pérez",
    telefono="+1234567890",
    email="juan@techdist.com"
)
assert str(proveedor) == "Tech Distributors SA - +1234567890"
assert proveedor.validar_email() == True
```

### Casos Borde

- [ ] Email sin símbolo @ (debe fallar validación)
- [ ] Teléfono con menos de 7 caracteres (debe fallar validación)
- [ ] Proveedor con nombre vacío (debe lanzar excepción)
- [ ] Creación sin dirección (debe usar cadena vacía por defecto)
