# 🟠 HU-014: Construir Menú Principal del Sistema CLI

**Sprint:** 6 | **Estimación:** 5 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** usuario del sistema,  
**Quiero** una interfaz de menú intuitiva en la consola,  
**Para** navegar fácilmente entre las diferentes funcionalidades.

---

## ✅ Criterios de Aceptación

### Menú Principal

- [ ] Opciones del menú:
  1. 📦 Gestión de Productos
  2. 📁 Gestión de Categorías
  3. 🏭 Gestión de Proveedores
  4. 🛒 Nueva Venta
  5. 📊 Reportes
  6. ⚙️ Configuración
  7. 🚪 Salir
- [ ] Validar entrada (solo números válidos)
- [ ] Bucle infinito hasta salir

### Diseño Visual

- [ ] Usar caracteres Unicode para bordes y emojis
- [ ] Limpiar pantalla entre menús (`os.system('clear')` o `'cls'`)
- [ ] Colores ANSI:
  - Rojo: errores
  - Verde: éxito
  - Azul/Cyan: títulos

### Manejo de Errores

- [ ] Capturar excepciones generales
- [ ] Validar entrada del usuario
- [ ] Opción volver al menú anterior

### Funciones Helper

- [ ] `limpiar_pantalla()` - Limpia consola
- [ ] `pausar()` - Espera Enter
- [ ] `mostrar_mensaje(texto, tipo)` - Mensaje con color
- [ ] `solicitar_entrada(prompt, tipo, validacion)`

### Clase CLI Principal

- [ ] Constructor recibe servicios por inyección
- [ ] Método `iniciar()` arranca aplicación
- [ ] Métodos privados para cada opción
