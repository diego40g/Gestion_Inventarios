# 🟠 HU-014: Construir Menú Principal del Sistema CLI

**Sprint:** 6 | **Estimación:** 5 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** usuario del sistema,  
**Quiero** una interfaz de menú intuitiva en la consola,  
**Para** navegar fácilmente entre las diferentes funcionalidades.

---

## ✅ Criterios de Aceptación

### Menú Principal

- [ ] Opciones del menú:
  1. 📦 Gestión de Productos
  2. 📁 Gestión de Categorías
  3. 🏭 Gestión de Proveedores
  4. 🛒 Nueva Venta
  5. 📊 Reportes
  6. ⚙️ Configuración
  7. 🚪 Salir
- [ ] Validar entrada usando `Scanner` (solo números válidos)
- [ ] Bucle infinito `while(true)` hasta salir
- [ ] Try-catch para manejar `InputMismatchException`

### Diseño Visual

- [ ] Usar caracteres Unicode para bordes y emojis
- [ ] Limpiar pantalla entre menús (usar escape ANSI `\033[H\033[2J` o `System.out.print("\033[H\033[2J")`)
- [ ] Colores ANSI:
  - Rojo (`\033[31m`): errores
  - Verde (`\033[32m`): éxito
  - Azul/Cyan (`\033[36m`): títulos
  - Reset (`\033[0m`): volver a normal

### Manejo de Errores

- [ ] Capturar excepciones generales con try-catch
- [ ] Validar entrada del usuario con `hasNextInt()`
- [ ] Opción volver al menú anterior
- [ ] Mensajes de error claros y amigables

### Clase MenuHelper (Utilidades)

- [ ] `public static void limpiarPantalla()` - Limpia consola
- [ ] `public static void pausar()` - Espera Enter con `scanner.nextLine()`
- [ ] `public static void mostrarMensaje(String texto, TipoMensaje tipo)` - Mensaje con color
- [ ] `public static String solicitarTexto(String prompt)` - Lee texto
- [ ] `public static int solicitarEntero(String prompt, int min, int max)` - Lee entero con validación
- [ ] Enum `TipoMensaje { ERROR, EXITO, INFO, ADVERTENCIA }`

### Clase CLI Principal

- [ ] Constructor recibe servicios por inyección de dependencias
- [ ] Atributo `private final Scanner scanner`
- [ ] Método `public void iniciar()` arranca aplicación
- [ ] Métodos privados para cada opción del menú:
  - `private void menuProductos()`
  - `private void menuCategorias()`
  - `private void menuProveedores()`
  - `private void menuNuevaVenta()`
  - `private void menuReportes()`
