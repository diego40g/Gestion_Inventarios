# 🟠 HU-009: Implementar Patrón Factory para Creación de Productos

**Sprint:** 4 | **Estimación:** 5 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** desarrollador del sistema,  
**Quiero** usar un Factory para crear productos de diferentes tipos,  
**Para** centralizar y simplificar la lógica de creación de objetos complejos.

---

## ✅ Criterios de Aceptación

### Enum TipoProducto

- [ ] Crear enum con valores: `FISICO`, `DIGITAL`, `PERECIBLE`
- [ ] Ubicación: `domain/producto.py`

### Clase ProductoFactory

- [ ] Método estático `crear(tipo: TipoProducto, **kwargs) -> ProductoBase`
- [ ] Retorna instancia correcta según tipo
- [ ] Valida kwargs contengan campos requeridos
- [ ] Lanza `ValueError` si tipo no reconocido
- [ ] Lanza `ValueError` si faltan parámetros

### Validaciones por Tipo

- [ ] ProductoFisico requiere: id, nombre, precio, stock, peso_kg, dimensiones
- [ ] ProductoDigital requiere: id, nombre, precio, tamaño_mb, formato, url_descarga
- [ ] ProductoPerecible requiere: id, nombre, precio, stock, fecha_vencimiento, temperatura_conservacion

### Método Helper

- [ ] `crear_desde_dict(datos: dict) -> ProductoBase`
- [ ] Extrae el tipo del diccionario
- [ ] Llama a `crear()` con los datos

---

## 🧪 Casos de Prueba

```python
# Crear producto físico
laptop = ProductoFactory.crear(
    TipoProducto.FISICO,
    id=1,
    nombre="Laptop Dell",
    precio=1200.00,
    stock=8,
    peso_kg=2.2,
    dimensiones="35x25x2 cm"
)
assert isinstance(laptop, ProductoFisico)

# Crear desde diccionario
datos = {
    "tipo": "perecible",
    "id": 3,
    "nombre": "Yogurt Natural",
    "precio": 2.99,
    "stock": 30,
    "fecha_vencimiento": "2026-02-20",
    "temperatura_conservacion": 4.0
}
yogurt = ProductoFactory.crear_desde_dict(datos)
assert isinstance(yogurt, ProductoPerecible)
```
