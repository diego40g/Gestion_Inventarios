# 🟠 HU-009: Implementar Patrón Factory para Creación de Productos

**Sprint:** 4 | **Estimación:** 5 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** desarrollador del sistema,  
**Quiero** usar un Factory para crear productos de diferentes tipos,  
**Para** centralizar y simplificar la lógica de creación de objetos complejos.

---

## ✅ Criterios de Aceptación

### Enum TipoProducto

- [ ] Crear enum: `public enum TipoProducto { FISICO, DIGITAL, PERECIBLE }`
- [ ] Ubicación: `src/main/java/ec/edu/istpet/inventario/domain/TipoProducto.java`

### Clase ProductoFactory

- [ ] Método estático `public static Producto crear(TipoProducto tipo, Map<String, Object> parametros)`
- [ ] Retorna instancia correcta según tipo usando switch
- [ ] Valida que parametros contengan campos requeridos
- [ ] Lanza `IllegalArgumentException` si tipo no reconocido
- [ ] Lanza `IllegalArgumentException` si faltan parámetros

### Validaciones por Tipo

- [ ] ProductoFisico requiere: nombre, precio, stock, pesoKg, dimensiones
- [ ] ProductoDigital requiere: nombre, precio, tamañoMB, formato, urlDescarga
- [ ] ProductoPerecible requiere: nombre, precio, stock, fechaVencimiento, temperaturaConservacion

### Método Helper

- [ ] `public static Producto crearDesdeJson(JsonObject json)`
- [ ] Extrae el tipo del JSON
- [ ] Convierte JsonObject a Map
- [ ] Llama a `crear()` con los datos

### Uso de Switch con Enums

- [ ] Implementar switch statement o switch expression (Java 14+)
- [ ] Cada case crea el tipo de producto correspondiente

---

## 🧪 Casos de Prueba

```java
// Crear producto físico
Map<String, Object> params = new HashMap<>();
params.put("nombre", "Laptop Dell");
params.put("precio", 1200.00);
params.put("stock", 8);
params.put("pesoKg", 2.2);
params.put("dimensiones", "35x25x2 cm");

Producto laptop = ProductoFactory.crear(TipoProducto.FISICO, params);
assertTrue(laptop instanceof ProductoFisico);
assertEquals("FISICO", laptop.getTipoProducto());

// Crear desde JSON
JsonObject json = new JsonObject();
json.addProperty("tipo", "PERECIBLE");
json.addProperty("nombre", "Yogurt Natural");
json.addProperty("precio", 2.99);
json.addProperty("stock", 30);
json.addProperty("fechaVencimiento", "2026-02-20");
json.addProperty("temperaturaConservacion", 4.0);

Producto yogurt = ProductoFactory.crearDesdeJson(json);
assertTrue(yogurt instanceof ProductoPerecible);
assertEquals("PERECIBLE", yogurt.getTipoProducto());
```
