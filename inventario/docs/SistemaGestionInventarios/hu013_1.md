# 🔴 HU-013: Desarrollar VentaService para Procesar Ventas

**Sprint:** 5 | **Estimación:** 8 SP | **Prioridad:** Crítica

---

## 📝 Descripción

**Como** cajero del sistema,  
**Quiero** procesar ventas que reduzcan automáticamente el stock,  
**Para** mantener el inventario actualizado en tiempo real.

---

## ✅ Criterios de Aceptación

### Constructor

- [ ] Constructor: `public VentaService(Repositorio<Venta> ventaRepo, Repositorio<Producto> productoRepo)`
- [ ] Inyección de dependencias de ambos repositorios
- [ ] Atributos `private final` para ambos repositorios

### Métodos Principales

- [ ] `public Venta crearVenta()` - Nueva venta vacía con ID generado
- [ ] `public boolean agregarItemAVenta(int ventaId, int productoId, int cantidad)`
  - Verifica producto existe usando `productoRepo.obtenerPorId()`
  - Verifica stock suficiente con `producto.tieneStock(cantidad)`
  - Crea ItemVenta y agrega a la venta
  - Retorna true si éxito, false si falla
- [ ] `public boolean eliminarItemDeVenta(int ventaId, int productoId)`
- [ ] `public void aplicarDescuento(int ventaId, EstrategiaDescuento estrategia)`
- [ ] `public boolean completarVenta(int ventaId)`
  - Valida que tenga items
  - Verifica stock nuevamente (por si cambió)
  - Reduce stock de cada producto usando `producto.reducirStock()`
  - Marca como completada
  - Guarda venta en repositorio
  - Actualiza productos en repositorio
  - Retorna true si éxito

### Métodos de Consulta

- [ ] `public Optional<Venta> obtenerVenta(int id)`
- [ ] `public List<Venta> listarVentas()`
- [ ] `public List<Venta> listarVentas(LocalDate desde, LocalDate hasta)`
- [ ] `public double calcularTotalVentasPeriodo(LocalDate desde, LocalDate hasta)`
- [ ] `public Map<String, Integer> obtenerProductosMasVendidos(int limite)`
  - Retorna mapa: nombre producto -> cantidad vendida
  - Usar Streams y Collectors para procesar

### Validaciones

- [ ] No completar venta sin items (lanzar `IllegalStateException`)
- [ ] No agregar items a venta completada (lanzar `IllegalStateException`)
- [ ] Verificar stock antes de completar
- [ ] Revertir cambios si falla reducción de stock (transaccionalidad básica)

### Integración con Observer

- [ ] Opcionalmente aceptar GestorInventario en constructor
- [ ] Al completar venta, notificar si stock queda bajo
- [ ] Integrar con sistema de alertas

### Manejo de Excepciones

- [ ] Capturar excepciones durante reducción de stock
- [ ] Log de errores apropiado
- [ ] Retornar false o lanzar excepción según el caso

---

## 🧪 Ejemplo de Uso

```java
Repositorio<Venta> ventaRepo = new VentaRepositorioJSON("data/ventas.json");
Repositorio<Producto> productoRepo = new ProductoRepositorioJSON("data/productos.json");
VentaService servicio = new VentaService(ventaRepo, productoRepo);

// Crear nueva venta
Venta venta = servicio.crearVenta();

// Agregar items (los IDs ya existen de productos creados previamente)
assertTrue(servicio.agregarItemAVenta(venta.getId(), 1, 2)); // 2 laptops
assertTrue(servicio.agregarItemAVenta(venta.getId(), 3, 5)); // 5 mouses

// Aplicar descuento
servicio.aplicarDescuento(venta.getId(), new DescuentoPorcentaje(10.0));

// Completar venta (reduce stock automáticamente)
assertTrue(servicio.completarVenta(venta.getId()));
```
