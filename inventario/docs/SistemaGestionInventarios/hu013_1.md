# 🔴 HU-013: Desarrollar VentaService para Procesar Ventas

**Sprint:** 5 | **Estimación:** 8 SP | **Prioridad:** Crítica

---

## 📝 Descripción

**Como** cajero del sistema,  
**Quiero** procesar ventas que reduzcan automáticamente el stock,  
**Para** mantener el inventario actualizado en tiempo real.

---

## ✅ Criterios de Aceptación

### Constructor

- [ ] `__init__(self, venta_repo: Repositorio[Venta], producto_repo: Repositorio[ProductoBase])`
- [ ] Inyección de dependencias de ambos repositorios

### Métodos Principales

- [ ] `crear_venta() -> Venta` - Nueva venta vacía
- [ ] `agregar_item_a_venta(venta_id, producto_id, cantidad) -> bool`
  - Verifica producto existe
  - Verifica stock suficiente
  - Crea ItemVenta y agrega
- [ ] `eliminar_item_de_venta(venta_id, producto_id) -> bool`
- [ ] `aplicar_descuento(venta_id, estrategia: EstrategiaDescuento)`
- [ ] `completar_venta(venta_id) -> bool`
  - Valida que tenga items
  - Verifica stock nuevamente
  - Reduce stock de cada producto
  - Marca como completada
  - Guarda en repositorio

### Métodos de Consulta

- [ ] `obtener_venta(id: int) -> Optional[Venta]`
- [ ] `listar_ventas(desde: Optional[date], hasta: Optional[date])`
- [ ] `calcular_total_ventas_periodo(desde, hasta) -> float`
- [ ] `obtener_productos_mas_vendidos(limite: int = 10)`

### Validaciones

- [ ] No completar venta sin items
- [ ] No agregar items a venta completada
- [ ] Verificar stock antes de completar
- [ ] Revertir si falla reducción (transaccionalidad)

### Integración con Observer

- [ ] Al completar venta, notificar si stock queda bajo
- [ ] Integrar con GestorInventario
