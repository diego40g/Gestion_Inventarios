# 🟠 HU-015: Implementar Menú de Gestión de Productos (CRUD)

**Sprint:** 6 | **Estimación:** 8 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** administrador del sistema,  
**Quiero** gestionar productos desde un menú dedicado,  
**Para** crear, listar, editar y eliminar productos del inventario.

---

## ✅ Criterios de Aceptación

### Menú de Productos

- [ ] Opciones:
  1. Listar todos los productos
  2. Buscar producto
  3. Agregar nuevo producto
  4. Editar producto
  5. Eliminar producto
  6. Ver productos con stock bajo
  7. Calcular valor del inventario
  8. Volver al menú principal

### Listar Productos

- [ ] Tabla formateada con: ID, Nombre, Tipo, Precio, Stock
- [ ] Usar `System.out.printf()` para formato alineado
- [ ] Mostrar encabezados de columna con líneas separadoras
- [ ] Mostrar total productos y valor inventario al final
- [ ] Paginación si hay más de 20 productos (usar ciclos y contador)

### Agregar Producto

- [ ] Solicitar tipo usando menú (1=Físico, 2=Digital, 3=Perecible)
- [ ] Solicitar datos comunes: nombre, precio, descripción
- [ ] Solicitar datos específicos según tipo:
  - Físico: peso (kg), dimensiones
  - Digital: tamaño (MB), formato, URL
  - Perecible: fecha vencimiento (formato ISO), temperatura
- [ ] Validar cada campo con try-catch
- [ ] Mostrar mensaje éxito con ID generado
- [ ] Capturar `IllegalArgumentException` para errores de validación

### Editar Producto

- [ ] Solicitar ID del producto con `MenuHelper.solicitarEntero()`
- [ ] Obtener y mostrar datos actuales en formato tabla
- [ ] Permitir editar campos individualmente
- [ ] Opción dejar sin cambios (presionar Enter)
- [ ] Confirmar cambios antes de guardar (S/N)
- [ ] Mensaje éxito o error

### Eliminar Producto

- [ ] Solicitar ID
- [ ] Mostrar datos del producto en formato tabla
- [ ] Solicitar confirmación (S/N) usando `MenuHelper.confirmar()`
- [ ] Eliminación lógica (soft delete) llamando `productoService.eliminarProducto()`
- [ ] Mensaje confirmación con color verde

### Buscar Producto

- [ ] Solicitar término de búsqueda (String)
- [ ] Llamar `productoService.buscarPorNombre(termino)`
- [ ] Mostrar resultados en tabla
- [ ] Opción ver detalles de un producto seleccionado
- [ ] Mensaje si no hay resultados

### Productos con Stock Bajo

- [ ] Solicitar umbral con valor default 10
- [ ] Llamar `productoService.productosConStockBajo(umbral)`
- [ ] Mostrar tabla productos con stock <= umbral
- [ ] Resaltar en rojo (ANSI) los con stock 0
- [ ] Formato: `\033[31m` para rojo, `\033[0m` para reset

### Formato de Tabla

```
╔═══════╦═════════════════════╦═══════════╦═══════════╦═══════╗
║  ID   ║       Nombre        ║   Tipo    ║  Precio   ║ Stock ║
╠═══════╬═════════════════════╬═══════════╬═══════════╬═══════╣
║   1   ║ Laptop HP           ║ FISICO    ║ $1299.99  ║  15   ║
║   2   ║ Ebook Java          ║ DIGITAL   ║   $29.99  ║  ∞    ║
╚═══════╩═════════════════════╩═══════════╩═══════════╩═══════╝
```
