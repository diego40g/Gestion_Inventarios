# 🟠 HU-015: Implementar Menú de Gestión de Productos (CRUD)

**Sprint:** 6 | **Estimación:** 8 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** administrador del sistema,  
**Quiero** gestionar productos desde un menú dedicado,  
**Para** crear, listar, editar y eliminar productos del inventario.

---

## ✅ Criterios de Aceptación

### Menú de Productos

- [ ] Opciones:
  1. Listar todos los productos
  2. Buscar producto
  3. Agregar nuevo producto
  4. Editar producto
  5. Eliminar producto
  6. Ver productos con stock bajo
  7. Calcular valor del inventario
  8. Volver al menú principal

### Listar Productos

- [ ] Tabla formateada: ID, Nombre, Tipo, Precio, Stock
- [ ] Usar `tabulate` o formato manual alineado
- [ ] Mostrar total productos y valor inventario
- [ ] Paginación si hay más de 20 productos

### Agregar Producto

- [ ] Solicitar tipo (Físico, Digital, Perecible)
- [ ] Solicitar datos comunes: nombre, precio, descripción
- [ ] Solicitar datos específicos según tipo:
  - Físico: peso, dimensiones
  - Digital: tamaño, formato, URL
  - Perecible: fecha vencimiento, temperatura
- [ ] Validar cada campo
- [ ] Mostrar mensaje éxito con ID generado
- [ ] Capturar errores de validación

### Editar Producto

- [ ] Solicitar ID del producto
- [ ] Mostrar datos actuales
- [ ] Permitir editar campos individualmente
- [ ] Opción dejar sin cambios (Enter)
- [ ] Confirmar cambios antes de guardar
- [ ] Mensaje éxito o error

### Eliminar Producto

- [ ] Solicitar ID
- [ ] Mostrar datos del producto
- [ ] Solicitar confirmación (S/N)
- [ ] Eliminación lógica (soft delete)
- [ ] Mensaje confirmación

### Buscar Producto

- [ ] Solicitar término de búsqueda
- [ ] Mostrar resultados en tabla
- [ ] Permitir seleccionar para ver detalles

### Productos con Stock Bajo

- [ ] Solicitar umbral (default: 10)
- [ ] Mostrar tabla productos con stock <= umbral
- [ ] Resaltar en rojo los con stock 0
