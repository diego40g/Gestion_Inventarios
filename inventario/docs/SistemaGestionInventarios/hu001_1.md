# 🔴 HU-001: Implementar Clase Categoria con Dataclasses

**Sprint:** 1 | **Estimación:** 2 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** desarrollador del sistema de inventario,  
**Quiero** crear la clase `Categoria` usando dataclasses de Python,  
**Para** representar las categorías de productos de forma simple y eficiente.

---

## ✅ Criterios de Aceptación

### Estructura de la Clase

- [ ] La clase debe usar el decorador `@dataclass`
- [ ] Atributos: `id: int`, `nombre: str`, `descripcion: str`, `activa: bool`
- [ ] El atributo `activa` debe tener valor por defecto `True`
- [ ] El atributo `descripcion` debe tener valor por defecto como cadena vacía

### Métodos Especiales

- [ ] Implementar el método `__str__` que retorne el formato: `"[{id}] {nombre}"`
- [ ] El método `__repr__` debe ser generado automáticamente por dataclass

### Validaciones Básicas

- [ ] El nombre no puede estar vacío
- [ ] El id debe ser un entero positivo

### Documentación

- [ ] La clase debe tener un docstring descriptivo
- [ ] Cada atributo debe tener su type hint correspondiente

---

## 🧪 Casos de Prueba

### Caso Normal

```python
categoria = Categoria(id=1, nombre="Electrónica", descripcion="Dispositivos electrónicos")
assert str(categoria) == "[1] Electrónica"
assert categoria.activa == True
```

### Casos Borde

- [ ] Crear categoría con nombre vacío (debe lanzar excepción)
- [ ] Crear categoría con id negativo (debe lanzar excepción)
- [ ] Crear categoría sin descripción (debe usar cadena vacía por defecto)
