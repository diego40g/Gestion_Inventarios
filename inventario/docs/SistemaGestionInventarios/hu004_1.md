# 🟠 HU-004: Refactorizar Producto con Getters/Setters y Validaciones

**Sprint:** 2 | **Estimación:** 5 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** desarrollador del sistema,  
**Quiero** refactorizar la clase `Producto` usando getters y setters apropiados,  
**Para** encapsular los datos y garantizar que siempre sean válidos.

---

## ✅ Criterios de Aceptación

### Atributos Privados

- [ ] Todos los atributos deben ser `private`
- [ ] Los atributos no deben ser accesibles directamente desde fuera de la clase

### Getters

- [ ] Crear getters públicos para todos los atributos
- [ ] Formato: `public TipoRetorno getNombreAtributo()`
- [ ] Para atributos booleanos: `public boolean isActivo()`

### Setters con Validaciones

- [ ] `setNombre(String nombre)` - Valida que no sea null o vacío, elimina espacios con `trim()`
- [ ] `setPrecio(double precio)` - Valida que no sea negativo, redondea a 2 decimales
- [ ] `setStock(int stock)` - Valida que no sea negativo
- [ ] Lanza `IllegalArgumentException` si validación falla

### Métodos de Gestión de Stock

- [ ] `public boolean reducirStock(int cantidad)` - Verifica stock antes de reducir
- [ ] `public void aumentarStock(int cantidad)` - Valida cantidad positiva
- [ ] Retorna boolean indicando éxito/fracaso

### Formato de Precio

- [ ] Usar `BigDecimal` en lugar de `double` para mayor precisión (opcional avanzado)
- [ ] O redondear correctamente con `Math.round(precio * 100.0) / 100.0`

---

## 🧪 Casos de Prueba

### Caso Normal

```java
Producto producto = new Producto("Teclado", "Teclado mecánico", 50.0, 20, 1, null);
assertEquals("Teclado", producto.getNombre());

producto.setPrecio(45.999);
assertEquals(46.0, producto.getPrecio(), 0.01);

assertTrue(producto.reducirStock(5));
assertEquals(15, producto.getStock());
```

### Casos Borde

- [ ] `setPrecio(-10.0)` debe lanzar `IllegalArgumentException`
- [ ] `setStock(-5)` debe lanzar `IllegalArgumentException`
- [ ] `reducirStock(20)` con stock de 15 debe retornar `false`
- [ ] `setNombre("")` debe lanzar `IllegalArgumentException`
