# 🟠 HU-010: Implementar Patrón Strategy para Descuentos en Ventas

**Sprint:** 4 | **Estimación:** 5 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** gerente de ventas,  
**Quiero** aplicar diferentes estrategias de descuento a las ventas,  
**Para** adaptar las promociones según el cliente o tipo de venta.

---

## ✅ Criterios de Aceptación

### Interface EstrategiaDescuento

- [ ] Declarar como `public interface EstrategiaDescuento`
- [ ] Método abstracto `double calcularDescuento(double monto)`
- [ ] Retorna monto del descuento (no el total con descuento)
- [ ] Ubicación: `src/main/java/ec/edu/istpet/inventario/application/estrategias/EstrategiaDescuento.java`

### Estrategia: SinDescuento

- [ ] Implementar `EstrategiaDescuento`
- [ ] `calcularDescuento()` retorna `0.0`
- [ ] Estrategia por defecto

### Estrategia: DescuentoPorcentaje

- [ ] Constructor: `public DescuentoPorcentaje(double porcentaje)`
- [ ] Validar porcentaje entre 0 y 100
- [ ] `calcularDescuento(monto)` retorna `monto * (porcentaje / 100.0)`

### Estrategia: DescuentoMontoFijo

- [ ] Constructor: `public DescuentoMontoFijo(double montoFijo)`
- [ ] Validar montoFijo positivo
- [ ] Retorna montoFijo pero nunca > monto total: `Math.min(montoFijo, monto)`

### Estrategia: DescuentoProgresivo

- [ ] Sin parámetros en constructor
- [ ] Rangos:
  - $0-$99.99: 0%
  - $100-$499.99: 5%
  - $500-$999.99: 10%
  - $1000+: 15%
- [ ] Implementar con if-else o switch

### Estrategia: DescuentoClienteFrecuente

- [ ] Constructor: `public DescuentoClienteFrecuente(int nivel)` (1, 2, o 3)
- [ ] Nivel 1 (Bronce): 5%
- [ ] Nivel 2 (Plata): 10%
- [ ] Nivel 3 (Oro): 15%
- [ ] Validar nivel entre 1 y 3

### Integración con Venta

- [ ] Atributo privado `private EstrategiaDescuento estrategiaDescuento`
- [ ] Método `public void aplicarEstrategia(EstrategiaDescuento estrategia)` para cambiar
- [ ] Método `public double calcularDescuento()` usa estrategia actual
- [ ] Inicializar con `new SinDescuento()` por defecto

---

## 🧪 Casos de Prueba

```java
Venta venta = new Venta();
venta.agregarItem(new ItemVenta(1, "Producto", 10, 100.0)); // $1000 total

// Sin descuento
assertEquals(0.0, venta.calcularDescuento(), 0.01);

// Descuento por porcentaje
venta.aplicarEstrategia(new DescuentoPorcentaje(10.0));
assertEquals(100.0, venta.calcularDescuento(), 0.01);

// Descuento progresivo
venta.aplicarEstrategia(new DescuentoProgresivo());
assertEquals(150.0, venta.calcularDescuento(), 0.01); // 15% de $1000

// Cliente frecuente
venta.aplicarEstrategia(new DescuentoClienteFrecuente(3)); // Oro
assertEquals(150.0, venta.calcularDescuento(), 0.01);
```
