# 🟠 HU-010: Implementar Patrón Strategy para Descuentos en Ventas

**Sprint:** 4 | **Estimación:** 5 SP | **Prioridad:** Alta

---

## 📝 Descripción

**Como** gerente de ventas,  
**Quiero** aplicar diferentes estrategias de descuento a las ventas,  
**Para** adaptar las promociones según el cliente o tipo de venta.

---

## ✅ Criterios de Aceptación

### Interface EstrategiaDescuento (ABC)

- [ ] Método abstracto `calcular_descuento(monto: float) -> float`
- [ ] Retorna monto del descuento (no el total con descuento)
- [ ] Ubicación: `application/estrategias/descuento.py`

### Estrategia: SinDescuento

- [ ] `calcular_descuento()` retorna 0.0
- [ ] Estrategia por defecto

### Estrategia: DescuentoPorcentaje

- [ ] Constructor: `__init__(self, porcentaje: float)`
- [ ] Validar porcentaje entre 0 y 100
- [ ] `calcular_descuento(monto)` retorna `monto * (porcentaje / 100)`

### Estrategia: DescuentoMontoFijo

- [ ] Constructor: `__init__(self, monto_fijo: float)`
- [ ] Validar monto_fijo positivo
- [ ] Retorna monto_fijo pero nunca > monto total

### Estrategia: DescuentoProgresivo

- [ ] Rangos:
  - $0-$99.99: 0%
  - $100-$499.99: 5%
  - $500-$999.99: 10%
  - $1000+: 15%

### Estrategia: DescuentoClienteFrecuente

- [ ] Constructor: `__init__(self, nivel: int)` (1, 2, o 3)
- [ ] Nivel 1 (Bronce): 5%
- [ ] Nivel 2 (Plata): 10%
- [ ] Nivel 3 (Oro): 15%

### Integración con Venta

- [ ] Atributo `estrategia_descuento: EstrategiaDescuento`
- [ ] Método `aplicar_estrategia(estrategia)` para cambiar
- [ ] `calcular_descuento()` usa estrategia actual
