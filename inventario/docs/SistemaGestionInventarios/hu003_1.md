# 🔴 HU-003: Crear Clase Abstracta Producto con Generación Automática de ID

**Sprint:** 1 | **Estimación:** 5 SP | **Prioridad:** Crítica

---

## 📝 Descripción

**Como** desarrollador del sistema,  
**Quiero** una clase abstracta `Producto` con generación automática de IDs únicos,  
**Para** tener una base sólida para todos los tipos de productos del inventario.

---

## ✅ Criterios de Aceptación

### Atributos Estáticos (de Clase)

- [ ] `private static int contadorProductos = 0` - Atributo estático compartido
- [ ] Debe incrementarse cada vez que se crea un nuevo producto

### Atributos de Instancia Privados

- [ ] `private int id` - Generado automáticamente
- [ ] `private String nombre`
- [ ] `private String descripcion`
- [ ] `private double precio`
- [ ] `private int stock`
- [ ] `private int categoriaId`
- [ ] `private Integer proveedorId` - Puede ser null (usando Integer wrapper)
- [ ] `private LocalDateTime fechaCreacion` - Generada automáticamente
- [ ] `private boolean activo`

### Métodos Estáticos

- [ ] `private static synchronized int generarId()` - Método estático que incrementa y retorna el contador
- [ ] Usar `synchronized` para thread-safety

### Constructores

- [ ] Constructor que genera el ID automáticamente
- [ ] Inicializa `fechaCreacion` con `LocalDateTime.now()`
- [ ] Validaciones en el constructor

### Métodos de Instancia

- [ ] `calcularValorStock()` - Retorna `precio * stock`
- [ ] `tieneStock(int cantidad)` - Retorna true si hay suficiente stock
- [ ] `toString()` - Retorna `"{nombre} ($precio) - Stock: {stock}"`

### Getters y Setters

- [ ] Getters para todos los atributos
- [ ] Setters con validaciones para `precio`, `stock`, `nombre`

### Validaciones

- [ ] El precio no puede ser negativo
- [ ] El stock no puede ser negativo
- [ ] El nombre no puede estar vacío o null

---

## 🧪 Casos de Prueba

### Caso Normal

```java
// Nota: Producto es abstracta, se crean instancias de subclases para probar
ProductoFisico producto1 = new ProductoFisico("Laptop", 999.99, 10, 2.0, "40x30x3");
ProductoFisico producto2 = new ProductoFisico("Mouse", 25.50, 50, 0.2, "10x5x3");

assertTrue(producto1.getId() > 0);
assertTrue(producto2.getId() > producto1.getId());
assertEquals(9999.90, producto1.calcularValorStock(), 0.01);
assertTrue(producto1.tieneStock(5));
assertFalse(producto1.tieneStock(15));
```

### Casos Borde

- [ ] Crear producto con precio negativo (debe lanzar `IllegalArgumentException`)
- [ ] Crear producto con stock negativo (debe lanzar `IllegalArgumentException`)
- [ ] Verificar que los IDs son únicos y secuenciales
- [ ] Crear producto sin proveedor (proveedorId debe ser null)
