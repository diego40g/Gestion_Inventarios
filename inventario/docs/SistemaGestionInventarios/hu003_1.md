# 🔴 HU-003: Crear Clase Base Producto con Generación Automática de ID

**Sprint:** 1 | **Estimación:** 5 SP | **Prioridad:** Crítica

---

## 📝 Descripción

**Como** desarrollador del sistema,  
**Quiero** una clase `Producto` base con generación automática de IDs únicos,  
**Para** tener una base sólida para todos los tipos de productos del inventario.

---

## ✅ Criterios de Aceptación

### Atributos de Clase

- [ ] `contador_productos: int = 0` - Debe ser un atributo de clase compartido
- [ ] Debe incrementarse cada vez que se crea un nuevo producto

### Atributos de Instancia

- [ ] `id: int` - Generado automáticamente usando `field(default_factory=...)`
- [ ] `nombre: str = ""`
- [ ] `descripcion: str = ""`
- [ ] `precio: float = 0.0`
- [ ] `stock: int = 0`
- [ ] `categoria_id: int = 0`
- [ ] `proveedor_id: Optional[int] = None`
- [ ] `fecha_creacion: datetime` - Generada automáticamente con `datetime.now()`
- [ ] `activo: bool = True`

### Métodos de Clase

- [ ] `_generar_id()` - Método de clase que incrementa y retorna el contador
- [ ] Debe usar el decorador `@classmethod`

### Métodos de Instancia

- [ ] `calcular_valor_stock()` - Retorna `precio * stock`
- [ ] `tiene_stock(cantidad: int = 1)` - Retorna True si hay suficiente stock
- [ ] `__str__()` - Retorna `"{nombre} (${precio:.2f}) - Stock: {stock}"`

### Validaciones

- [ ] El precio no puede ser negativo
- [ ] El stock no puede ser negativo
- [ ] El nombre no puede estar vacío

---

## 🧪 Casos de Prueba

### Caso Normal

```python
producto1 = Producto(nombre="Laptop", precio=999.99, stock=10)
producto2 = Producto(nombre="Mouse", precio=25.50, stock=50)

assert producto1.id == 1
assert producto2.id == 2
assert producto1.calcular_valor_stock() == 9999.90
assert producto1.tiene_stock(5) == True
assert producto1.tiene_stock(15) == False
```

### Casos Borde

- [ ] Crear producto con precio negativo (debe lanzar excepción)
- [ ] Crear producto con stock negativo (debe lanzar excepción)
- [ ] Verificar que los IDs son únicos y secuenciales
- [ ] Crear producto sin proveedor (debe ser None)
