# 🟡 HU-011: Implementar Patrón Observer para Alertas de Stock

**Sprint:** 4 | **Estimación:** 5 SP | **Prioridad:** Media

---

## 📝 Descripción

**Como** administrador del sistema,  
**Quiero** recibir notificaciones automáticas cuando el stock esté bajo,  
**Para** reordenar productos a tiempo y evitar faltantes.

---

## ✅ Criterios de Aceptación

### Observadores Concretos

- [ ] `NotificadorConsola implements Observador` - Imprime mensajes en consola con colores ANSI
- [ ] `NotificadorLog implements Observador` - Escribe en archivo `logs/stock_alerts.log` usando `java.util.logging`
- [ ] `NotificadorEmail implements Observador` (Mock) - Simula envío de email para tests

### Clase GestorInventario (Sujeto)

- [ ] Implementar interface `Sujeto`
- [ ] Atributo: `private int umbralStockBajo` (default: 10)
- [ ] Atributo: `private Map<Integer, Producto> productos` (usar HashMap)
- [ ] Atributo: `private List<Observador> observadores` (usar ArrayList)
- [ ] Método `public void registrarProducto(Producto producto)`
- [ ] Método `public void venderProducto(int id, int cantidad)` notifica si stock <= umbral
- [ ] Método `public void reponerStock(int id, int cantidad)` notifica cuando se repone

### Niveles de Alerta

- [ ] **BAJO**: stock <= umbral y > 0 → "⚠️ Stock Bajo"
- [ ] **AGOTADO**: stock == 0 → "🚨 Stock Agotado"
- [ ] **REPUESTO**: stock vuelve > umbral → "✅ Stock Repuesto"

### Múltiples Observadores

- [ ] Permitir agregar múltiples observadores con `agregarObservador()`
- [ ] Todos reciben notificación simultáneamente iterando la lista
- [ ] Permitir eliminar observadores con `eliminarObservador()`

### Manejo de Logs

- [ ] Usar `java.util.logging.Logger` para NotificadorLog
- [ ] Crear directorio `logs/` si no existe usando `Files.createDirectories()`
- [ ] Formato de log: `[FECHA] [NIVEL] mensaje`

---

## 🧪 Casos de Prueba

```java
GestorInventario gestor = new GestorInventario(5); // umbral = 5
NotificadorConsola notificadorConsola = new NotificadorConsola();
NotificadorLog notificadorLog = new NotificadorLog("logs/stock_alerts.log");

gestor.agregarObservador(notificadorConsola);
gestor.agregarObservador(notificadorLog);

ProductoFisico teclado = new ProductoFisico(1, "Teclado", 50.0, 10, 0.5, "30x10x3");
gestor.registrarProducto(teclado);

// Vender y reducir a stock bajo
gestor.venderProducto(1, 6);
// Debe notificar "Stock Bajo" a ambos observadores

// Vender todo
gestor.venderProducto(1, 4);
// Debe notificar "Stock Agotado"

// Reponer
gestor.reponerStock(1, 20);
// Debe notificar "Stock Repuesto"
```
