# 🟡 HU-011: Implementar Patrón Observer para Alertas de Stock

**Sprint:** 4 | **Estimación:** 5 SP | **Prioridad:** Media

---

## 📝 Descripción

**Como** administrador del sistema,  
**Quiero** recibir notificaciones automáticas cuando el stock esté bajo,  
**Para** reordenar productos a tiempo y evitar faltantes.

---

## ✅ Criterios de Aceptación

### Observadores Concretos

- [ ] `NotificadorConsola` - Imprime mensajes en consola con colores
- [ ] `NotificadorLog` - Escribe en `logs/stock_alerts.log`
- [ ] `NotificadorEmail` (Mock) - Simula envío de email para tests

### Clase GestorInventario (Sujeto)

- [ ] Heredar de interface `Sujeto`
- [ ] Atributo: `umbral_stock_bajo: int` (default: 10)
- [ ] Atributo: `productos: Dict[int, ProductoBase]`
- [ ] Método `registrar_producto(producto)`
- [ ] Método `vender_producto(id, cantidad)` notifica si stock <= umbral
- [ ] Método `reponer_stock(id, cantidad)` notifica cuando se repone

### Niveles de Alerta

- [ ] **BAJO**: stock <= umbral y > 0 → "⚠️ Stock Bajo"
- [ ] **AGOTADO**: stock == 0 → "🚨 Stock Agotado"
- [ ] **REPUESTO**: stock vuelve > umbral → "✅ Stock Repuesto"

### Múltiples Observadores

- [ ] Permitir agregar múltiples observadores
- [ ] Todos reciben notificación simultáneamente
- [ ] Permitir eliminar observadores

---

## 🧪 Casos de Prueba

```python
gestor = GestorInventario(umbral_stock_bajo=5)
notificador = NotificadorEmail("admin@tienda.com")
gestor.agregar_observador(notificador)

teclado = ProductoFisico(1, "Teclado", 50.0, 10, 0.5, "30x10x3")
gestor.registrar_producto(teclado)

# Vender y reducir a stock bajo
gestor.vender_producto(1, 6)
# Debe notificar "Stock Bajo"

# Vender todo
gestor.vender_producto(1, 4)
# Debe notificar "Stock Agotado"

# Reponer
gestor.reponer_stock(1, 20)
# Debe notificar "Stock Repuesto"
```
