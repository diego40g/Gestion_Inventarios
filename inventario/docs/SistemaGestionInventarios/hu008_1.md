# 🔴 HU-008: Implementar Patrón Repository con Persistencia JSON

**Sprint:** 3 | **Estimación:** 8 SP | **Prioridad:** Crítica

---

## 📝 Descripción

**Como** usuario del sistema,  
**Quiero** que mis datos se guarden automáticamente en archivos JSON,  
**Para** no perder información cuando cierre la aplicación.

---

## ✅ Criterios de Aceptación

### BaseRepositorioJSON[T]

- [ ] Implementar `Repositorio[T]`
- [ ] Constructor: `__init__(self, ruta_archivo: str)`
- [ ] Método privado `_cargar_datos() -> List[dict]`
- [ ] Método privado `_guardar_datos(datos: List[dict])`
- [ ] Manejo de archivo no existente (crear vacío)
- [ ] Manejo de JSON inválido

### ProductoRepositorioJSON

- [ ] Heredar de `BaseRepositorioJSON[ProductoBase]`
- [ ] Implementar todos los métodos CRUD
- [ ] Método `_producto_a_dict(producto)` para serialización
- [ ] Método `_dict_a_producto(datos)` para deserialización
- [ ] Incluir campo 'tipo' en JSON (fisico/digital/perecible)
- [ ] Manejar fechas correctamente (ISO string)

### VentaRepositorioJSON

- [ ] Similar a ProductoRepositorioJSON
- [ ] Serializar lista de ItemVenta correctamente
- [ ] Archivo: `data/ventas.json`

### Archivos JSON

- [ ] `data/productos.json`
- [ ] `data/ventas.json`
- [ ] `data/categorias.json`
- [ ] `data/proveedores.json`
- [ ] Crear con `[]` si no existen
