# 🔴 HU-008: Implementar Patrón Repository con Persistencia JSON

**Sprint:** 3 | **Estimación:** 8 SP | **Prioridad:** Crítica

---

## 📝 Descripción

**Como** usuario del sistema,  
**Quiero** que mis datos se guarden automáticamente en archivos JSON,  
**Para** no perder información cuando cierre la aplicación.

---

## ✅ Criterios de Aceptación

### Dependencia Gson

- [ ] Verificar que Gson esté en `pom.xml` para serialización JSON
- [ ] Importar `com.google.gson.Gson` y `GsonBuilder`

### BaseRepositorioJSON<T>

- [ ] Clase abstracta que implementa `Repositorio<T>`
- [ ] Constructor: `protected BaseRepositorioJSON(String rutaArchivo)`
- [ ] Método protegido `protected List<JsonObject> cargarDatos()`
- [ ] Método protegido `protected void guardarDatos(List<JsonObject> datos)`
- [ ] Manejo de archivo no existente (crear vacío con `[]`)
- [ ] Manejo de JSON inválido con try-catch

### ProductoRepositorioJSON

- [ ] Implementar `Repositorio<Producto>` (heredar de clase base si existe)
- [ ] Implementar todos los métodos CRUD
- [ ] Método `private JsonObject productoAJson(Producto producto)` para serialización
- [ ] Método `private Producto jsonAProducto(JsonObject json)` para deserialización
- [ ] Incluir campo "tipo" en JSON ("FISICO", "DIGITAL", "PERECIBLE")
- [ ] Manejar fechas con `DateTimeFormatter.ISO_LOCAL_DATE_TIME`
- [ ] Usar ProductoFactory para crear instancias al deserializar

### VentaRepositorioJSON

- [ ] Similar a ProductoRepositorioJSON
- [ ] Serializar lista de ItemVenta correctamente usando Gson
- [ ] Archivo: `src/main/resources/data/ventas.json`

### Archivos JSON

- [ ] `src/main/resources/data/productos.json`
- [ ] `src/main/resources/data/ventas.json`
- [ ] `src/main/resources/data/categorias.json`
- [ ] `src/main/resources/data/proveedores.json`
- [ ] Crear con `[]` si no existen usando `Files.createDirectories()`

### Manejo de Excepciones

- [ ] Capturar `IOException` para errores de archivo
- [ ] Capturar `JsonSyntaxException` para JSON inválido
- [ ] Log de errores apropiado

---

## 🧪 Ejemplo de Uso

```java
ProductoRepositorioJSON repo = new ProductoRepositorioJSON("data/productos.json");
ProductoFisico laptop = new ProductoFisico("Laptop Dell", 999.99, 10, 2.5, "40x30x3");
repo.agregar(laptop);

Optional<Producto> recuperado = repo.obtener(laptop.getId());
assertTrue(recuperado.isPresent());
assertEquals("Laptop Dell", recuperado.get().getNombre());
```
