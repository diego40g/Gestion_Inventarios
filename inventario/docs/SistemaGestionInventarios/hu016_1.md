## ✅ Criterios de Aceptación

### Tests para Producto

- [ ] Test creación de cada tipo de producto
- [ ] Test `calcular_precio_final()` para cada tipo
- [ ] Test validaciones (precio negativo, stock negativo)
- [ ] Test métodos específicos (dias_para_vencer, generar_enlace)
- [ ] Test polimorfismo (lista mixta de productos)

### Tests para Venta

- [ ] Test agregar/eliminar items
- [ ] Test cálculos (subtotal, descuento, total)
- [ ] Test completar venta con reducción de stock
- [ ] Test validaciones (venta sin items, cantidad negativa)
- [ ] Test estado (no modificar venta completada)

### Tests para Repositorios

- [ ] Test CRUD completo
- [ ] Test persistencia (guardar y recuperar)
- [ ] Test búsquedas
- [ ] Test con archivo vacío
- [ ] Test con JSON corrupto

### Tests para Estrategias

- [ ] Test cada estrategia de descuento
- [ ] Test validaciones
- [ ] Test casos borde

### Tests para Observer

- [ ] Test agregar/eliminar observadores
- [ ] Test notificaciones
- [ ] Test múltiples observadores

### Configuración de Pytest

- [ ] Crear `pytest.ini` o `pyproject.toml`
- [ ] Usar fixtures para datos de prueba
- [ ] Usar `tmpdir` para archivos temporales
- [ ] Configurar coverage con `pytest-cov`

## 📝 Estructura de Tests

### conftest.py - Fixtures Compartidas

```python
@pytest.fixture
def producto_fisico():
    return ProductoFisico(1, "Laptop", 999.99, 10, 2.0, "35x25x2")

@pytest.fixture
def repositorio_temporal(tmpdir):
    archivo = tmpdir.join("test_productos.json")
    return ProductoRepositorioJSON(str(archivo))
```

### Ejemplo de Test

```python
def test_crear_producto_fisico():
    producto = ProductoFisico(1, "Test", 100.0, 10, 1.0, "10x10x10")
    assert producto.tipo_producto == "FISICO"
    assert producto.calcular_precio_final() > 100.0

def test_precio_negativo_lanza_excepcion():
    with pytest.raises(ValueError):
        ProductoFisico(1, "Test", -10.0, 10, 1.0, "10x10x10")
```
